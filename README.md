# SQL-анализ транзакций клиентов

Набор SQL-запросов (MySQL 8.0+, с использованием CTE и оконных функций) для анализа покупательской активности клиентов за период **01.06.2015 – 01.06.2016**.

## Файлы

### `SQL_1_task.sql` — Непрерывная история покупок клиентов
Находит клиентов с покупками в каждом месяце периода без пропусков (13 месяцев подряд). Для каждого такого клиента в разрезе месяцев рассчитывается:
- сумма покупок за месяц;
- средний чек за месяц и за весь период;
- средняя сумма покупок за месяц (за весь период);
- количество операций за месяц и за весь период.

### `SQL_2_task.sql` — Помесячная динамика продаж
Помесячная агрегация по всей базе клиентов:
- средняя сумма чека и среднее количество операций в месяц;
- среднее количество активных клиентов в месяц;
- доля операций и доля выручки каждого месяца от годового итога;
- разбивка по полу (M/F/NA) — доля операций и доля затрат по каждому месяцу.

### `SQL_3_task.sql` — Возрастная сегментация клиентов
Группировка клиентов по возрасту (шаг 10 лет, отдельная группа «Нет данных») с поквартальной статистикой:
- количество операций и сумма по каждой возрастной группе;
- средний чек и средняя сумма операции по кварталам;
- доля группы в общем количестве операций и выручке квартала (%).

## Технологии
- MySQL 8.0+ (CTE, оконные функции `OVER(PARTITION BY ...)`, `DATE_FORMAT`, `QUARTER`, `FIELD`)

## Структура данных
Запросы работают со схемой `transactions_customers`:
- `transactions` (`date_new`, `Id_check`, `ID_client`, `Count_products`, `Sum_payment`)
- `customers` (`Id_client`, `Total_amount`, `Gender`, `AGE`, ...)
